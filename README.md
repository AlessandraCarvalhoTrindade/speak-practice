# 🗣️ Speak Practice

Aplicação web para praticar conversação em inglês usando **reconhecimento e síntese de voz**.

O usuário escolhe um tema, ouve a pergunta em inglês, responde falando e recebe uma sugestão de resposta com tradução.

---

## ✨ Funcionalidades

- 4 temas de conversação: Apresentação, Trabalho, Viagem e Cotidiano
- Síntese de voz (Text-to-Speech) para ouvir a pergunta
- Reconhecimento de voz (Speech-to-Text) para responder falando
- Sugestão de resposta em inglês + tradução em português
- Interface simples e responsiva

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Web Speech API (SpeechSynthesis + SpeechRecognition)

> **Obs:** Funciona melhor no Google Chrome.
